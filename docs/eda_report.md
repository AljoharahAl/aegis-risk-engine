# EDA Report: Give Me Some Credit

## 1. Dataset Overview
- This report covers credit data about 150,000 borrowers from the Kaggle
  competition "Give Me Some Credit" (file: cs-training.csv).
- The goal is to understand the data before building a model that predicts
  whether a borrower will have a serious delinquency within two years.
- Size: 150,000 rows and 12 columns.
- Target: SeriousDlqin2yrs (1 = serious delinquency, 0 = no delinquency).
- The first column "Unnamed: 0" is only a row index, so it will be dropped.
